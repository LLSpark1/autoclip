# Selling checklist (for you, not customers)

1. **Test** the installers from the Releases page on a real Windows PC and Mac.
2. **Choose a name** that nobody else uses. Change `APP_NAME` in `app.py`.
3. **Pick a store.** Whop is where clippers are; Gumroad also works. Both give license
   keys, which Claude can add to the app.
4. **Price:** about $29 one-time, or $9/month with updates.
5. **Sell** by posting clips made with the app in clipping Discords and on TikTok.

**Removing the security warnings** buyers see on first launch costs money:
- Mac: Apple Developer Program ($99/year) for signing and notarizing.
- Windows: a code-signing certificate (about $100-300/year).
Claude can add both to the build once you have them.
