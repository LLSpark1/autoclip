# AutoClip Studio

Drop in a long video (podcast, stream, interview) and get vertical clips for
TikTok, YouTube Shorts and Reels, with captions, a headline, and a post caption.

## Start

1. Install Python from https://www.python.org/downloads/
   (on Windows, tick **"Add python.exe to PATH"**).
2. Double-click **Start on Windows.bat** or **Start on Mac.command**
   (Mac, first time: right-click → Open).

The first start takes about 5 minutes to set up. Then the app opens in your browser.

## Use

1. Drop in your video.
2. Click **Make my clips**.

Your clips are saved in the **AutoClip Clips** folder in your home folder.

**Tip:** In **Settings**, add an Anthropic API key (from console.anthropic.com) for much
better clip picks, headlines and captions. It costs a few cents per hour of video.

Only clip videos you own or have permission to use.
